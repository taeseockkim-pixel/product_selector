Apps Script 수정 안내
=====================

목표
----
제품선택가이드 화면은 Vercel 앱을 그대로 사용하고,
Google Drive / Sheet / Gmail 처리는 Apps Script 권한으로 실행되게 합니다.

사용자 접속 흐름:
사용자 -> Apps Script 웹 앱 URL -> 내부 iframe에서 Vercel 제품선택가이드 표시 -> 저장/메일은 Apps Script가 처리


1. Index.html 수정
------------------
Apps Script 프로젝트의 기존 Index.html 내용을 전부 삭제하고,
아래 텍스트 파일의 복사 구간을 그대로 붙여넣으세요.

붙여넣을 파일:
D:\smart_quote_sys\product_selector\APPS_SCRIPT_Index_html_전체교체코드.txt

중요:
- 기존의 예전 스마트 견적 관리 시스템 HTML은 더 이상 Index.html에 두면 안 됩니다.
- 이 파일은 Vercel 제품선택가이드를 iframe으로 보여주는 wrapper 화면입니다.


2. Code.gs 수정
---------------
Apps Script 프로젝트의 기존 Code.gs 내용을 전부 삭제하고,
아래 텍스트 파일의 내용을 그대로 붙여넣으세요.

붙여넣을 파일:
D:\smart_quote_sys\product_selector\APPS_SCRIPT_Code_gs_전체교체코드.txt

중요:
- 이 전체 교체용 Code.gs는 제품선택가이드 wrapper와 견적 저장/PDF/Gmail 초안 생성에 필요한 함수만 담았습니다.
- 기존 예전 화면용 사용자 관리, 제품 드롭다운, 예전 HTML용 함수는 제거됩니다.
- Gemini AI 요약용 CONFIG.GEMINI_API_KEY는 전체 교체용 Code.gs 파일에 기존 값으로 반영되어 있습니다.


3. wrapper-code.patch.gs 내용에서 확인할 값
------------------------------------------
wrapper-code.patch.gs 맨 위에 아래 값이 있습니다.

const VERCEL_APP_URL = 'https://product-selector-two.vercel.app';

이 값은 현재 Vercel 제품선택가이드 주소입니다.
다른 Vercel 도메인을 쓰려면 이 값만 변경하면 됩니다.


4. Apps Script 저장 및 배포
--------------------------
수정 후 아래 순서로 진행하세요.

1) Apps Script에서 저장
2) 배포 > 배포 관리
3) 현재 웹 앱 배포 선택
4) 연필 아이콘 또는 수정 클릭
5) 버전을 새 버전으로 선택
6) 액세스 권한: CIMON의 모든 사용자
7) 실행 사용자: 나
8) 배포 업데이트
9) 배포 관리 화면의 웹 앱 URL을 복사


5. 접속 URL
-----------
앞으로 사용자는 Vercel URL이 아니라 Apps Script 웹 앱 URL로 접속합니다.

예:
https://script.google.com/a/macros/cimon.com/s/.../exec

주의:
- 라이브러리 URL이 아닙니다.
- 편집기 URL이 아닙니다.
- 반드시 웹 앱 URL이며 /exec 로 끝나는 주소입니다.


6. 정상 동작 확인
----------------
Apps Script 웹 앱 URL로 접속했을 때 아래처럼 보여야 정상입니다.

정상:
- CIMON 제품 선택 가이드 화면이 보임
- PLC / IPC / SCADA / XPANEL 제품 선택 화면이 보임
- 견적 요청서 작성 화면으로 이동 가능

비정상:
- 예전 스마트 견적 관리 시스템 화면이 그대로 보임

비정상일 때 확인할 것:
1) Index.html을 Index.wrapper.html 내용으로 교체했는지 확인
2) Code.gs의 doGet(e)를 wrapper-code.patch.gs 내용으로 교체했는지 확인
3) 새 버전으로 배포 업데이트했는지 확인
4) 예전 배포 URL이 아니라 최신 웹 앱 URL로 접속 중인지 확인


7. Vercel 환경변수
------------------
이 wrapper 방식으로 운영할 때는 Vercel의 APPS_SCRIPT_WEB_APP_URL은 필수가 아닙니다.

이유:
- Vercel 서버가 Apps Script를 직접 호출하지 않습니다.
- 사용자가 Apps Script 웹 앱에 접속합니다.
- 저장/메일 요청은 iframe -> Apps Script wrapper -> google.script.run 으로 처리됩니다.

따라서 현재 Vercel에 APPS_SCRIPT_WEB_APP_URL이 남아 있어도 큰 문제는 없지만,
운영 접속은 Apps Script 웹 앱 URL을 사용해야 합니다.
