# 견적 품목 행 정렬·입력칸 크기·품목 번호 가독성 개선

- 완료일: 2026-10-22
- 범위: 견적 작성 화면의 품목 입력 행(`QuoteFormPage.tsx`)

## 배경

품목 행 하단의 `상세 / 수량 / 단가 / 배율 / 금액 / 삭제`가 서로 다른 높이와 너비를 사용해 위아래 선이 어긋났다.
수량 칸은 좁고 단가 칸은 넓어 같은 입력 그룹으로 보이지 않았으며, 품목 번호가 `3. 모델명`처럼 11px 보조 글씨에
묻혀 몇 번째 품목인지 알아보기 어렵다는 의견이 있었다.

## 변경 내용

- **품목 번호 배지**: 좌측 순서 조정 열에 `01`, `02` … 두 자리 번호를 36px 이상 배지(18px 굵은 숫자, 연한 파란 배경)로
  표시했다. 드래그 핸들과 위/아래 이동 버튼은 배지 아래에 유지했다. 모델명 라벨에 붙던 중복 번호(`3.`)는 제거했다.
- **공통 높이 규격**: 하단 6개 항목의 라벨을 `h-5`(20px), 컨트롤을 `h-10`(40px)으로 통일해 라벨·입력칸·금액·버튼의
  위아래 선이 정확히 맞도록 했다. 상세 버튼이 없는 품목도 40px 자리와 `—` 표시를 유지해 정렬이 흔들리지 않는다.
- **모델명·규격 정렬**: `수기작성` 배지 때문에 모델명 라벨이 규격 라벨보다 높아지던 문제를 막기 위해 두 라벨을
  `h-5`(20px)로 고정하고 같은 baseline에 맞췄다. 두 입력칸은 더 많은 줄 수(`Math.max`)를 공통으로 사용해
  한쪽만 줄이 늘어나도 위아래 선이 어긋나지 않는다.
- **입력칸 크기 통일**: 수량·단가·배율을 모두 같은 120px 너비로 배치하고 글씨를 14px로 통일했다. 수량은 가운데,
  단가·배율·금액은 오른쪽 정렬이며 숫자 폭 고정(`tabular-nums`)을 적용해 값이 바뀌어도 흔들리지 않는다.
- **반응형 재배치**: 넓은 화면은 6열 한 줄, 중간은 3열 2줄, 좁은 화면은 2열 3줄로 재배치한다. 입력칸을 억지로
  줄이지 않아 가로 스크롤 없이 사용할 수 있다.
- 금액 표시는 입력칸처럼 보이던 테두리를 없애 읽기 전용 값임을 구분했다.
