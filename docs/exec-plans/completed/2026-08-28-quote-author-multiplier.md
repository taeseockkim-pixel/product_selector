# 견적 요청서 기타 작성자 및 배율

## 목표

견적 요청서에 등록되지 않은 작성자를 입력할 수 있게 하고, 품목별 배율을 적용해 금액을 계산한다.

## 완료 내용

- 작성자 선택에 `기타` 추가
- `기타` 선택 시 작성자·연락처·이메일 직접 입력 및 필수 검증
- 품목별 배율 입력 추가, 기본값 `1`
- 품목 금액을 `단가 × 배율 × 수량`으로 계산
- 미리보기, 인쇄 HTML, CSV, 로컬 서버 및 Apps Script에 배율 반영
- 고객용 Excel/PDF 출력에는 배율 열 없이 유효 단가(단가×배율)와 금액만 표시

## 배포 시 주의

운영 Apps Script를 사용하는 경우 `APPS_SCRIPT_Code_gs_전체교체코드.txt`의 변경 내용을
Apps Script `Code.gs`에 반영한 뒤 새 Web App 버전으로 배포해야 한다.
