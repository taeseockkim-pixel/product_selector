|---|---|
| PLC CM1 CPU (UP/XP/CP) | 연산 방식, 프로그램 언어, 타이머/카운터, 내장 시리얼, 베이스 증설, 고속 카운터, 동작온도, 보호등급 |

| IPC Panel PC | 메모리(RAM), 스토리지, LAN/USB/COM 포트, DisplayPort, 전원, 동작온도 |
| IPC Rack/Box PC | LAN, USB, COM, 전원, 동작온도, 메모리 |
| SCADA | 지원 OS, 드라이버 수, 트렌드/알람/레포트, 통신 프로토콜, DB 연동 |
| PLC I/O 모듈 | 입출력 범위, 응답시간, 절연방식, 동작온도 |

## 방법

Node.js 스크립트로 제품 유형(`subType`)별 공통 스펙을 일괄 추가.
`addSpec(specs, label, value)` 헬퍼로 중복 추가 방지.
