# 견적 품목 모델명 다중 줄 입력 및 카드형 행 정리

- 완료일: 2026-10-15
- 범위: 견적 작성 화면의 품목 입력 행과 제품 추가 영역

## 변경 내용

- Product_Prise 가격표 품목을 포함한 모든 견적 품목의 모델명을 여러 줄 `textarea`로 변경했다. Enter로 줄바꿈할 수 있고, 내용 길이와 명시적 줄바꿈에 맞춰 높이가 늘어난다.
- 모델명·규격은 위쪽 넓은 영역에, 수량·단가·배율·금액·삭제는 아래 줄에 배치하는 카드형 행으로 통일했다. 기존 좁은 한 줄 품목 행은 제거했다.
- 품목 표 헤더는 카드형 행과 어울리도록 `모델명 / 사양 · 수량 / 단가 / 배율 / 금액` 통합 제목으로 정리했다.
- 제품 추가 영역은 시트/제품/수량/추가 버튼의 폭을 조정하고, 선택한 제품의 규격 미리보기를 두 줄 잘림 대신 줄바꿈이 유지되는 스크롤 상자로 표시한다.
- 모델명을 수정하면 기존 로직대로 `isCustom`이 되어 `수기작성` 배지가 붙는 동작은 유지한다.
