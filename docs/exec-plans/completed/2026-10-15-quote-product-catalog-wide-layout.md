# Product_Prise 견적 품목 입력 폭 개선

- 완료일: 2026-10-15
- 범위: 견적 작성 화면의 Product_Prise 가격표 품목

## 변경 내용

- Product_Prise에서 추가한 품목도 수기작성 품목과 동일하게 모델명·규격을 넓은 별도 영역에 표시한다.
- 수량·단가·배율·금액·삭제 컨트롤을 그 아래 줄에 배치해 PDF 출력의 제품명/규격/가격 정보 구성을 작성 화면에서도 쉽게 비교할 수 있게 했다.
- 이 시점에는 가격표 모델명을 한 줄 입력으로 유지했다. 이후 같은 날 후속 요청으로 Product_Prise 모델명을 포함한 모든 견적 품목 모델명의 여러 줄 입력을 허용했다.
- 화면 미리보기·HTML 인쇄와 Excel/PDF 줄바꿈 보존은 기존 다중 줄 처리 및 회귀 테스트를 유지한다.

## 검증

- `npm run test:quote-layout`: Product_Prise/수기 행 구조, 출력 개행/Excel 행 높이 및 1페이지 PDF 통과 (당시 기준 가격표 모델명 한 줄 유지 확인 포함)
- `npm run verify`: 전체 통과
