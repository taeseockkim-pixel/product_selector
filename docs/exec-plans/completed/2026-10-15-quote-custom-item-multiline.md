# 수기 견적 품목 다중 줄 입력

- 완료일: 2026-10-15
- 범위: 견적 작성 화면의 수기작성 품목 및 견적 출력 미리보기

## 변경 내용

- `수기작성` 품목의 모델명과 규격을 나란히 넓은 여러 줄 입력란으로 표시한다. 긴 내용과 직접 입력한 줄바꿈에 맞춰 textarea 높이를 늘린다.
- 수량·단가·배율·금액·삭제 컨트롤은 품명/규격 아래 줄에 배치한다.
- Product_Prise 가격표에서 추가한 상품의 모델명 입력은 기존 한 줄 컨트롤을 유지한다.
- 이름·규격 문자열의 줄바꿈은 견적 초안/저장 데이터에 그대로 두고, 화면 미리보기·HTML 인쇄·Excel 셀에도 표시한다. Excel은 입력된 개행과 자동 줄바꿈을 반영해 행 높이를 계산한다.

- `npm run verify`: 25/25 통과
