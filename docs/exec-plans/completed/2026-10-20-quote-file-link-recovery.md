# 견적 파일링크 경로 복구 안전성

- 완료일: 2026-10-20
- 범위: Apps Script 견적 스냅샷/파일링크 복구 및 로컬 에이전트 `/files`

## 변경 내용

- 에이전트 완료 결과에 실제 폴더명과 PDF 파일명을 포함하고 Apps Script가 이를 스냅샷의 `details.actualFolderName`/`pdfFileNames`에 저장한다. 신규 링크 복구는 계산된 업체명 경로 대신 이 실제 경로를 우선 사용한다.
- Apps Script 자동 파일링크 복구는 P열 셀이 완전히 비어 있고 실제 경로 메타데이터가 있는 행만 채운다. 기존 RichText 링크나 일반 텍스트를 다시 계산한 URL로 덮어쓰지 않으며, 경로 메타데이터가 없는 구형 스냅샷으로 추측 링크를 만들지 않는다.
- `/files`는 기존 HMAC 검증을 유지하면서 요청 경로가 없을 때 동일 부서·연도 하위에서 요청 파일명/견적번호가 유일하게 일치하는 파일만 찾아 제공한다. 일치 파일이 없거나 모호하면 임의의 첫 파일을 반환하지 않고 진단 로그를 남긴다.
- `/health`와 heartbeat에 에이전트 버전·호스트·`publicBaseUrl`·절대 경로를 공개하지 않는 저장 루트 지문을 추가했다.
- 기존 대장 행·파일·폴더를 이동, 삭제 또는 재생성하지 않았다.

## 검증

- `npm run test:agent-e2e`: 견적 PDF를 다른 폴더로 옮긴 격리된 테스트에서 서명된 링크가 정확한 파일을 찾는지 확인
- `npm run test:quote-draft`: 실제 폴더/파일명 기반 Apps Script 링크 생성 및 기존 링크 보호 회귀 테스트
- `npm run test:agent-queue`
- `npm run verify`

## 운영 복구 보류

- 2026-10-20 확인한 운영 `/health`는 `2026-10-13-excel-pdf-attachments` 버전이었다. 새 진단 필드를 운영에서 확인하려면 서버 PC 코드를 갱신하고 에이전트를 재시작해야 한다.
- 영업 `2610-003`은 대장 링크가 이미 있으므로 자동 복구 대상이 아니다. 결과 JSON/스냅샷과 저장소의 실제 PDF 위치를 먼저 확인해야 하며, 견적 파일 이동·이름 변경·재생성은 승인 없이 수행하지 않는다.
