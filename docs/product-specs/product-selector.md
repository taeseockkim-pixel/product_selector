# 제품 선택 가이드 — 기능 스펙

## 목적

CIMON 영업/기술 지원 담당자가 고객 요구사항에 맞는 제품을 빠르게 찾아 제안할 수 있도록 지원.

---

## 사용자 시나리오

### 시나리오 A — PLC 선정
1. PLC 탭 선택 → CM1(대형) 또는 CM3(소형) 선택
2. 좌측 트리에서 "CPU 모듈 > UP Series" 선택
3. 제품 목록에서 원하는 I/O 점수·성능의 모델 확인
4. "상세" 버튼 → 전체 사양 확인
5. "담기" → 담기 목록으로 이동 → 고객에게 제안

### 시나리오 B — IPC 선정
1. IPC/IAC 탭 → 패널 PC 선택
2. 화면 크기, CPU 등급, 터치 방식 필터 적용
3. 여러 제품을 "비교" 버튼으로 추가
4. 비교 페이지에서 스펙 나란히 확인

### 시나리오 C — 통합 구성
1. PLC, IPC, SCADA 각각 담기
2. 담기 목록 페이지에서 전체 구성 확인

## 기능 상세

### 필터링
- **PLC**: 시리즈(CM1/CM3) × 모듈 유형 (CPU/전원/베이스/I/O/통신)
- **IPC**: 화면 크기 / CPU 등급 / 터치 방식 / 고휘도 / SCADA 탑재 여부
- **SCADA**: 에디션(SCADA/SCADA-PRO) / 라인업(DS/RS/VS) / 태그 수 / 동시접속 수
- **XPANEL**: OS / 화면 크기 / 전원 / 광온도 여부

### 상세 사양 모달
- 클릭: 제품 테이블의 "상세" 버튼
- 표시 내용: `product.specs[]` 전체 항목을 테이블로 렌더링
- 오버레이 클릭 또는 × 버튼으로 닫기

### 담기 (Cart)
- 최대 제한 없음
- 담기/취소 토글 (+ / ✓ 버튼)
- 담기 목록 페이지: 모델명, 시리즈, 설명 표시 + 제거 버튼
- 전체 비우기 지원

### 비교
- 최대 4개 제한 권장 (현재 미적용)
- 비교 페이지: 각 제품의 specs 항목을 컬럼으로 배치
- 비교 제거 개별/전체 지원
