## 1. 시스템 소개

**CIMON 스마트 견적관리 시스템**은 다음을 하나로 통합한 내부 견적 관리 도구입니다.

- **제품 선택 가이드**: PLC / IPC / SCADA / XPANEL 제품 필터링·비교·담기
- **견적서 작성**: 담은 제품으로 견적서를 만들고, 가격표 기반 품목을 추가
- **견적관리대장(구글 시트)**: 부서별로 견적 내역이 자동 기록
- **견적 파일 자동 생성**: XLSX·PDF 견적서가 사내 파일 서버(172.35.12.36)에 자동 저장
- **발주 관리**: 발주 체크와 발주등록 요청 메일(첨부 포함) 자동 작성
- **AI 대장 검색**: 자연어로 대장 내용을 검색·분석

> 견적서 **파일(XLSX/PDF)은 사내 파일 서버**에, **대장(목록)은 구글 시트**에 각각 저장됩니다. 구글 드라이브 용량은 파일이 아닌 시트만 사용하므로 거의 차지하지 않습니다.

## 2. 시작하기 — 접속과 로그인

### 2-1. 접속 주소

회사에서 안내된 **Google Apps Script 웹앱 주소**로 접속합니다.
(주소 형식: `https://script.google.com/macros/s/.../exec`)

> 접속하면 회사 로고(CIMON)와 "스마트 견적관리 시스템" 화면이 열립니다.

### 2-2. Google 계정 로그인

- 시스템은 **회사 Google 계정(도메인)**으로만 사용할 수 있습니다.
- 처음 접속하면 Google 로그인과 권한 승인(권한 요청)이 나타날 수 있습니다. 회사 계정으로 로그인하고 **[허용]**을 눌러 주세요.
- **작성자 DB에 등록된 계정만** 견적 기능을 사용할 수 있습니다. 등록되지 않은 계정으로 접속하면 "견적 관리 기능에 접근 권한이 없습니다"라는 안내가 뜹니다. 이 경우 관리자에게 **계정 등록을 요청**해 주세요.

### 2-3. 부서 확인

- 화면 상단에 **부서 배지**(예: `부서: 기술영업`)가 표시됩니다.
- 일반 사용자는 **본인 부서의 대장만** 보고 작성할 수 있습니다.
- **관리자**는 상단 드롭다운으로 **모든 부서**(기술영업 / 영업 / 프로젝트)를 전환할 수 있습니다.

## 3. 견적서 작성하기

### 3-1. 기본 흐름

1. **제품 담기**: 제품 선택 가이드에서 원하는 제품을 **담기**합니다.
2. 상단의 **견적서 작성** 버튼을 누릅니다.
3. 견적서 작성 화면에서 다음을 입력합니다.

### 3-2. 입력 항목

| 구분 | 내용 |
|---|---|
| **고객 정보** | 업체명 · 담당자 · 연락처 · 이메일 |
| **작성자** | 본인 계정이 자동 선택됩니다 (작성자 DB 기준). 연락처·이메일이 비어 있으면 직접 입력할 수 있습니다. |
| **거래 조건** | 납품 장소 · 납품 기한 · 결제 조건 · 유효 기간 · 포장 · 비고 |
| **품목** | 담은 제품 + 가격표에서 제품군/품명을 골라 **제품 추가** (수량·단가·배율 조정 가능) |

> **고객정보 자동 매칭**: 업체명이나 담당자를 입력하고 다른 칸으로 이동하면, 같은 부서 대장의 기존 고객 정보를 찾아 자동으로 채워줍니다. 업체명·담당자·연락처·이메일이 모두 일치하는 중복 데이터는 1개만 표시되며, 여러 건의 다른 정보가 있을 경우 **기존 견적서 번호**와 함께 선택 창이 뜹니다.

> **수기 품목 및 기술지원비 작성**: 제품 추가 영역에서 `+ 기술지원비`, `+ 출장비`, `+ 직접 작성` 버튼을 클릭하여 엔지니어링 기술료나 특수 품목을 수기로 입력할 수 있으며, 추가된 품목의 품명/제품명과 규격 사양을 자유롭게 직접 편집할 수 있습니다.

> **미완성 초안 자동 저장**: 입력 중인 내용은 계정별로 자동 저장됩니다. 페이지를 이동하거나 브라우저를 닫았다가 다시 열어도 복원됩니다. 지우려면 **초기화** 버튼을 누르세요.

### 3-3. 저장 / 메일 초안 생성

- **견적서 생성(저장)**: 견적번호(예: `기술영업 2609-001`)가 먼저 예약되고 사내 파일 서버에 XLSX·PDF가 생성됩니다. **파일 생성이 성공한 뒤에만** 견적관리대장에 행과 파일링크가 기록됩니다. 파일 생성에 실패하면 대장에 새 행을 만들지 않습니다.
- **메일 초안 생성**: 제목·본문을 확인·수정한 뒤 생성하면, **본인 Gmail 임시보관함**에 견적서 PDF가 첨부된 메일 초안이 만들어집니다. 이후 Gmail에서 최종 확인 후 발송하세요.

> 품목이 14개를 넘으면 견적서가 `견적번호_1`, `견적번호_2` … 여러 파일로 자동 분할 생성됩니다.

## 4. 견적 목록(대장) 사용하기

상단의 **견적 목록** 버튼을 누르면 대장 화면이 열립니다.

### 4-1. 화면 구성

- **부서 배지 / 부서 선택**: 현재 부서(관리자는 전환 가능)
- **연도 선택**: 해당 부서 폴더에 실제 대장이 있는 연도만 표시됩니다.
- **AI 검색**: 자연어로 대장을 검색합니다 (자세한 내용은 [8장](#8-ai-대장-검색)).
- **대시보드**: AI 검색 옆 버튼에서 **영업 통계 대시보드**를 확인합니다. **견적 파이프라인 분석**과 **발주(수주) 실적 분석**으로 탭이 분리되어 제안 활동과 실제 수주 매출 지표를 독립적으로 분석할 수 있습니다.
- **새로고침 / 대장 검색 / 폴더 / 견적서 작성**

### 4-2. 대장 항목

| 항목 | 설명 |
|---|---|
| NO · 연도 · 월 · 일 | 견적 일련번호와 작성일 |
| **발주** | 발주 여부 체크박스 (자세한 내용은 [6장](#6-발주-관리-발주-체크박스와-발주등록-요청-메일)) |
| 견적번호 · 업체명 · 고객명 · 연락처 · 이메일 | 견적 기본 정보 |
| 제품 항목 · 제품명 · **적용현장** · 견적 금액 · 비고 | 견적 내용 (적용현장 클릭 시 확인/취소 창으로 수정 및 저장) |
| **파일링크** | 생성된 견적서 PDF/XLSX 링크 (클릭하면 새 탭에서 열림) |
| **액션** | 수정 · 업로드 · 삭제 버튼 |

### 4-3. 견적 삭제

대장에서 해당 견적의 **삭제** 버튼을 누르면 삭제 방식 선택 창이 열립니다.

1. **삭제 방식 선택**:
   - **라인삭제 (기본)**: 대장에 **검은 취소선**을 표시하고 견적번호는 유지합니다. 취소선이 표시된 견적은 액션 열에 **복원** 버튼이 표시되어 되돌릴 수 있습니다.
   - **영구삭제**: 대장 행·스냅샷·로컬 폴더를 모두 삭제하고, 다음 견적 생성 시 **빈 번호를 재사용**합니다.
2. 하단의 **[확인]** 버튼을 누르면 **"정말 삭제하시겠습니까?" 재확인 팝업 창**이 뜹니다.
3. 팝업 창에서 **[확인]**을 한 번 더 눌러야 안전하게 최종 삭제가 실행됩니다. (취소를 누르면 실행되지 않습니다.)

### 4-4. 검색과 정렬

- **기본 정렬**: 대장 진입 시 **견적번호 기준 내림차순(최신 견적이 맨 위)**으로 자동 정렬됩니다.
- **정렬 변경**: 각 **헤더를 클릭**하면 오름차순(↑) / 내림차순(↓)으로 정렬됩니다.
- **대장 검색**: 입력란에 검색어를 입력하면 업체명, 견적번호, 제품명뿐만 아니라 **작성자 이름(영업사원 실명)**으로도 실시간 검색됩니다.
- 같은 결과가 여러 건이면 선택 창에서 특정 견적을 고를 수 있습니다.

### 4-5. 파일링크로 견적서 열기

- **파일링크**의 PDF/XLSX를 클릭하면 새 탭에서 바로 열립니다.
- 링크가 아직 생성되지 않은 견적은 잠시 후(파일 생성 후) 자동으로 채워집니다.

### 4-6. 적용 현장 작성 및 수정

대장의 **적용현장** 칸에서 해당 견적이 납품·적용되는 현장명을 바로 작성하고 관리할 수 있습니다.

1. 대장 목록의 **적용현장** 칸(또는 `+ 현장 입력` 버튼)을 클릭합니다.
2. 입력 창이 열리면 현장명(예: `여수 2공장 PLC 개보수`, `세종 데이터센터`)을 입력합니다.
3. **[확인]** 버튼을 누르면 재확인 창이 뜬 후, 구글 시트 **견적관리대장의 '적용현장' 열에 즉시 저장**됩니다.
4. **[취소]**를 누르면 저장되지 않고 원래 상태로 유지됩니다.

### 4-7. 대장 항목(열) 표시/숨김 및 순서 설정

대장 상단의 **[⚙ 열 설정]** 버튼을 눌러 본인 업무 스타일에 맞게 테이블 항목을 맞춤 설정할 수 있습니다.

1. **표시 / 숨김**: 보지 않아도 되는 열(예: 연락처, 이메일 등)의 체크를 해제하면 테이블에서 숨겨집니다.
2. **순서 변경**: 각 항목 우측의 **▲ / ▼ 화살표**를 눌러 열의 좌우 순서를 자유롭게 바꿀 수 있습니다.
3. **설정 자동 저장**: 변경한 열 구성은 브라우저에 자동 저장되어, 새로고침하거나 재접속해도 그대로 유지됩니다.
4. **기본값 복원**: 언제든 **[↺ 기본값 복원]** 버튼을 누르면 초기 순서와 전체 표시로 원상 복구됩니다.

## 5. 견적 수정하기 (리비전)

### 5-1. 수정 방법

1. 대장에서 수정할 견적의 **수정** 버튼을 누릅니다.
2. 원본 견적이 폼에 불러와집니다 (고객 정보, 품목, 금액 등).
3. 내용을 수정한 뒤 **견적서 생성(저장)**을 누릅니다.

### 5-2. 미리보기 창에서 생성 방식 선택 (신규 견적서 vs 기존 견적서에 Rev)

수정 폼에서 **견적서 미리보기**를 누르면 미리보기 창 상단에 체크 옵션이 나타납니다.

1. **신규 견적서로 생성 (체크 시)**:
   - 기존 견적번호와 무관하게 **완전히 새로운 견적번호(다음 채번 번호, 예: `기술영업 2609-446`)가 발급**됩니다.
   - [저장]이나 [이메일 발송]을 누르면 대장에 새 행으로 등록되어 신규 견적서처럼 발행됩니다 (기존 견적 복사/신규 발행 시 유용).
2. **기존 견적서에 Rev으로 생성 (체크 시, 기본값)**:
   - [저장]이나 [이메일 발송]을 누르면 기존 수정 프로세스가 진행되며, 다음 중 하나를 선택할 수 있습니다:
     - **다른 이름으로 저장 (새 리비전 생성)**: `견적번호_Rev01`, `Rev02` … 와 같이 새 리비전 번호로 추가 저장.
     - **기존 파일에 덮어쓰기**: 기존 버전 목록 중 덮어쓸 대상 파일을 선택하여 해당 파일 내용만 수정본으로 교체.

> **주의**: 이 시스템으로 **저장된 견적만** 수정할 수 있습니다. 과거에 대장에만 기록되고 스냅샷(원본 데이터)이 없는 견적은 "수정 가능한 원본 데이터가 없습니다"라고 안내됩니다.

## 6. 발주 관리 (발주 체크박스와 발주등록 요청 메일)

### 6-1. 발주 체크(미발주 → 발주)

1. 미발주 견적의 **발주 체크박스**를 클릭합니다.
2. **"발주 처리 방식 선택"** 창이 열립니다.
   - **발주등록 요청 메일 작성**: 사내 발주 담당자(김유빈 대리)에게 보낼 메일 초안 작성 창을 열고, 발주를 완료 처리합니다.
   - **메일 발송 없이 발주 등록**: 메일을 쓰지 않고 **대장에 발주 완료(체크) 상태만 즉시 기록**합니다.
   - **취소**: 아무것도 변경하지 않고 창을 닫습니다.

### 6-2. 발주등록 요청 메일 작성

새 탭의 발주등록 요청 메일 페이지에서 다음을 입력·선택합니다.

- **납품 주소 (필수)**: 입력하지 않으면 메일을 작성할 수 없습니다.
- **첨부 파일 선택 (필수)**: 172.35.12.36 로컬 PC의 해당 견적 폴더 파일 목록이 표시됩니다.
  - **생성된 견적서 XLSX·PDF**와 **업로드한 문서**(발주서, 사업자등록증 등)가 모두 보입니다.
  - 로컬 폴더 파일을 직접 선택하므로 구글 드라이브 문서 폴더 접근 권한이 필요하지 않습니다.
  - 1개 이상 체크해야 합니다.
- **[임시보관함 작성]**을 누르면 메일 초안이 생성됩니다.

### 6-3. 생성되는 메일

| 항목 | 내용 |
|---|---|
| 보낸사람 | **본인 계정** (로그인한 담당자) |
| 받는사람 | 김유빈 대리 |
| 참조 | 김태석 차장 · 정성택 차장 · 한진희 차장 · 장재석 상무 · 김원중 상무 · 제어기기영업팀 |
| 제목 | `[발주서] {업체명}- {제품명} 발주서 공유` |
| 본문 | `&부서`는 견적 부서에 따라 자동 표기됩니다 (기술영업→기술영업실, 영업→자동화영업실, 프로젝트→프로젝트사업실) |

- 초안은 **본인 Gmail 임시보관함**에 저장되고, 자동으로 임시보관함이 열립니다. **최종 확인 후 직접 발송**하세요.
- 작성이 완료되면 발주 체크박스가 체크 처리됩니다.

### 6-4. 발주 해제

- 이미 발주 체크된 견적의 체크박스를 다시 누르면 **"발주를 해제 하시겠습니까?"** 확인 창이 뜹니다.
- **[예]**를 누르면 발주가 해제됩니다 (메일은 발송되지 않습니다).

## 7. 서류 업로드와 파일 열람

### 7-1. 서류 업로드

1. 대장에서 해당 견적의 **업로드** 버튼을 누릅니다.
2. 새 탭에서 **견적 서류 업로드** 페이지가 열립니다 (처음에는 부서 비밀번호 로그인이 필요할 수 있습니다).
3. 파일을 선택하고 **[업로드]**를 누릅니다.

- **허용 형식**: PDF · HWP · Word · Excel · 이미지 · PPT · ZIP 등 대부분 (실행 파일 `.exe` 등은 제외)
- **파일 크기**: 최대 1GB
- 업로드한 파일은 해당 견적 폴더에 저장되고, 발주 메일 첨부 선택지에도 표시됩니다.

### 7-3. 견적통계 시트 (자동 생성)

- 에이전트가 각 부서 폴더에 **`견적통계.xlsx`**를 자동 생성·갱신합니다.
- 시트 구성: **견적요약** · **품목상세** · **업체별요약** · **제품별요약**
- 기존 견적서는 에이전트 시작 시 자동 스캔되어 채워지고, 이후 새 견적 저장 시 자동 추가됩니다.
- 엑셀 필터·피벗으로 자유롭게 분석할 수 있으며, 파일은 로컬 PC에만 저장됩니다.
- 대시보드의 **품목 상세 분석** 섹션도 이 통계 데이터를 기반으로 표시됩니다.

### 7-4. 영업 통계 대시보드

대장 상단의 **대시보드** 버튼을 누르면 영업 통계 대시보드가 열립니다.

- **다차원 필터링 및 스마트 차트**:
  - **담당자 필터**: 특정 영업 담당자(작성자)를 선택하여 개인별 견적/수주 실적만 독립 집계할 수 있습니다.
  - **기간/일자 필터**:
    - **연간 전체**: 1월~12월 월별 추이와 연간 누적 실적 표시 (대장의 451건 전체 100% 집계 보장)
    - **월별 선택**: 특정 월(예: 9월)을 클릭하면 해당 월의 **일별(1일~말일) 실적 추이**로 차트가 자동 전환
    - **주간 선택**: 특정 월의 **1주차~5주차**를 클릭하면 해당 주의 **7일간 일별 실적 추이**로 차트가 정밀 전환
    - **일자 지정**: 시작일~종료일 달력 선택을 통해 특정 기간 동안의 실적만 맞춤 조회
  - **인터랙티브 차트 호버**: 데이터 포인트에 마우스 오버 시 상단 짤림 없이 위치가 자동 반전(Smart Flip)되어 정확한 금액과 건수를 선명하게 확인 가능합니다.
- **견적 파이프라인 분석 탭**:
  - 4대 제품군(PLC/IPC/SCADA/XPANEL) 외 모든 특수 항목(기타)까지 포함하여 **전체 451건 견적이 100% 누락 없이 집계**됩니다.
  - 총 견적 금액, 총 견적 건수, 건당 평균 견적액(AOV), 견적 의뢰 고객사 수, 수주 전환율(Win Rate)
  - 월별 견적 발행 추이 (인터랙티브 차트)
  - 영업팀별 견적 파이프라인 비교
  - 제품군별 견적 제안 비중 & 상위 견적 의뢰 고객사 TOP 8
  - 영업 담당자별 견적 발행 현황 & 다빈도 제안 제품 모델
  - 견적 세부 품목 분석 & 진행 중인 고액 영업 기회 (미수주 파이프라인)
  - 견적 문의 중단 고객사 리스트
- **발주(수주) 실적 분석 탭 (ERP 발주 파일 실시간 연동)**:
  - **발주 내역 파일 자동 연동**: `D:\folders\공유\견적서\{부서}\{연도}\발주 내역\` 폴더 내의 **항상 가장 최신 파일**을 기준으로 실질적인 ERP 수주 실적을 완벽 분석합니다.
  - **[📁 발주 내역 파일 업로드] 버튼**: 대시보드 상단 버튼을 클릭하여 새 엑셀 파일(.xlsx)을 업로드하면 즉시 최신 발주 데이터로 갱신됩니다.
  - **실질 수주 지표**: 총 수주 금액 (약 6억 2,800만 원), 총 수주 건수, 건당 평균 수주액, 실제 구매 고객사 수
  - **주요 거래처 TOP 랭킹**: 실제 수주액 기준 핵심 고객사 랭킹 (Key Accounts)
  - **영업 담당자별 수주 실적**: 실제 ERP 담당자별(조규광, 정성택, 한진희, 김태석 등) 수주 실적 및 수주율 랭킹
  - **실제 수주 베스트셀러 모델**: 발주 확정된 품목별 판매 수량 및 매출액 랭킹
  - **최근 확정 발주 내역**: 최근 수주 완료된 주문 내역 테이블 (주문번호, 고객사, 금액, 일자)

### 7-2. 파일 열람 (폴더 브라우저)

1. 대장 상단의 **폴더** 버튼을 누르면 파일 열람 페이지로 이동합니다.
2. **부서 비밀번호**로 로그인합니다 (관리자는 관리자 비밀번호로 모든 부서 열람 가능).
3. 폴더를 탐색하고, 파일 옆의 **[열기]**(새 탭 미리보기) 또는 **[다운로드]**를 누릅니다.
4. **이름 기준 정렬**: 파일 열람 테이블 헤더의 **`이름 ▲ / ▼`**를 클릭하면 목록이 **오름차순(가나다 순) 또는 내림차순(역순)**으로 즉시 정렬됩니다.

> **로그인 부서와 견적 부서가 다르면** "로그인 부서와 견적 부서가 다릅니다" 안내가 뜹니다. 이때는 로그아웃 후 **관리자 비밀번호**로 로그인하면 모든 부서를 볼 수 있습니다.

## 8. AI 대장 검색

자연어로 대장 내용을 검색·분석할 수 있습니다.

### 8-1. 사용 방법

1. 대장 화면에서 **AI 검색** 버튼을 누릅니다.
2. **개인 OpenRouter API 키**를 입력하고 **[연결 확인]**을 누릅니다.
   - 키는 브라우저나 서버에 저장되지 않으며, 세션마다 다시 입력합니다.
   - **API 키 변경** 버튼으로 연결을 지우고 새 키를 입력할 수 있습니다.
3. AI 모델(기본 `openrouter/auto`)과 ZDR 옵션을 확인합니다.
4. 질문을 입력하고 **[질문하기]**를 누릅니다.

### 8-2. 질문 예시

- "이번 연도 견적 금액이 가장 큰 제품군과 금액을 알려줘"
- "발주 완료된 견적서가 있어?"
- "○○업체 견적 총액을 알려줘"

> **검색 범위**: 현재 부서의 선택된 연도 대장만 분석합니다. 담당자·연락처·이메일이 포함되므로 **ZDR(데이터 비저장) 사용을 권장**합니다.

## 11. 자주 묻는 질문 (FAQ)

**Q1. 견적 목록이 안 열리고 "접근 권한이 없습니다"가 떠요.**
→ 회사 Google 계정으로 로그인했는지, 그리고 계정이 작성자 DB에 등록되어 있는지 확인하세요. 미등록이면 관리자에게 등록을 요청하세요.

**Q1-1. "구글 드라이브 공유 폴더(견적에이전트) 접근 권한이 없습니다" 또는 "액세스가 거부됨: DriveApp"이 떠요.**
→ 이 시스템은 각 사용자의 Google Drive 권한으로 공유 폴더(견적에이전트, 부서 폴더, 대장 등)에 접근합니다. 해당 리소스가 본인 계정과 공유되어 있지 않으면 이 오류가 납니다. **관리자에게 공유 폴더 접근 권한을 요청**하세요. (관리자는 Apps Script 편집기에서 `diagnoseUserDriveAccess`를 실행해 계정별 접근 가능 여부를 확인할 수 있습니다.)

**Q2. 파일링크가 비어 있어요.**
→ 견적 파일은 저장 후 1~3분 뒤에 생성됩니다. 잠시 후 새로고침하면 자동으로 채워집니다.

**Q3. 파일링크를 눌렀는데 파일이 안 열려요.**
→ 대장 새로고침 후 다시 시도하세요. 그래도 안 되면 관리자에게 문의하세요.

**Q4. 수정 버튼을 눌렀는데 "수정 가능한 원본 데이터가 없습니다"가 떠요.**
→ 시스템으로 저장된 견적만 수정할 수 있습니다. 과거에 대장에만 기록된 견적은 수정할 수 없습니다.

**Q5. 발주 메일 작성 시 "첨부 가능한 파일이 없습니다"가 떠요.**
→ 모달의 **[업로드]** 버튼으로 발주서·사업자등록증을 먼저 올린 뒤 **[새로고침]**을 누르세요. 방금 올린 파일은 구글 드라이브 동기화(1~3분) 후에 표시됩니다.

**Q6. 발주 메일 초안이 안 만들어져요.**
→ 납품 주소를 입력했는지, 첨부 파일을 1개 이상 체크했는지 확인하세요. 두 가지는 필수입니다.

**Q7. 업로드 페이지에서 "로그인 부서와 견적 부서가 다릅니다"가 떠요.**
→ 파일 서버에 다른 부서로 로그인되어 있는 상태입니다. 로그아웃 후 **관리자 비밀번호**로 로그인하면 모든 부서를 사용할 수 있습니다.

**Q8. 모바일에서 파일 서버가 안 열려요.**
→ 파일 서버는 사내망 전용입니다. 사내 Wi-Fi에 연결된 상태에서 접속하세요.

**Q9. AI 검색이 안 돼요.**
→ OpenRouter API 키를 먼저 입력하고 **[연결 확인]**을 눌러야 합니다. 키는 저장되지 않으므로 매번 입력합니다.

**Q10. 견적을 삭제하고 싶어요.**
→ 삭제 기능은 제공하지 않습니다. 잘못 작성된 견적은 대장에서 직접 비고란에 표시하거나 관리자에게 문의하세요.
